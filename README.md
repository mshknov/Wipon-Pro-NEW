# Wipon Pro — прототип мобильного экрана

Интерактивный HTML/CSS/JS-прототип экрана приложения **Wipon Pro**: статус прибора, подписка и тарифы, баланс и пополнение, раздел «ГИД» с вопросами и ответами.

> ⚠️ Это **демо-прототип**. Лицевой счёт, баланс, тарифы и платёжная форма — заглушки. Реальных платежей и запросов к серверу нет, данные карты никуда не отправляются.

## Возможности

- Статус прибора и прогресс-бар оставшегося срока подписки
- Тарифы: Wipon PRO, Wipon PRO Plus, Wipon Auto — переключение и продление
- Разделы «Акцизка» и «Маркировка» с блокировкой пунктов, недоступных на текущем тарифе
- Пополнение баланса (форма карты с маской ввода и базовой валидацией)
- Раздел «ГИД» (FAQ)
- Адаптивная вёрстка под мобильный экран (до 430 px), доступность: `aria-*`, фокус с клавиатуры, закрытие окон по `Esc`

## Запуск

Сборка не нужна — это обычная статика.

```bash
git clone https://github.com/<your-username>/wipon-pro-prototype.git
cd wipon-pro-prototype

# вариант 1: просто открыть index.html в браузере
# вариант 2: локальный сервер
python3 -m http.server 8000
# → http://localhost:8000
```

Для лучшего вида откройте в браузере в режиме эмуляции мобильного устройства (DevTools → Ctrl+Shift+M).

## Настройка демо-данных

В начале `js/app.js` задаются тестовые значения:

| Переменная | Назначение |
|---|---|
| `DAYS_LEFT`, `TOTAL` | осталось дней / длительность периода |
| `ACCOUNT` | номер лицевого счёта (демо) |
| `balance`, `TARIFF` | баланс и стоимость подписки, ₸ |
| `PLANS` | список тарифов, цены и описание |

## Публикация на GitHub Pages

1. Загрузите проект в репозиторий (ветка `main`).
2. Откройте **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. После пуша workflow `pages.yml` опубликует сайт по адресу  
   `https://<your-username>.github.io/wipon-pro-prototype/`
